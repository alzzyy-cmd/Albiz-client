GPL-3.0-only desktop/mobile Fabric fork and decompiled recovery of Anubis Client by **4ldenz**. This is an independent modified recovery project, not an official upstream build. See [NOTICE](NOTICE.md) and [LICENSE](LICENSE).

**Temiz derleme başarılı; 49 otomatik test geçti. Oyun/Android/OpenGL/sunucu testi yapılmadı.** Ayrıntı, kapsam ve bilinen sınırlar: [docs/STATUS.md](docs/STATUS.md).

## Derleme
Java **21**, Gradle wrapper **9.4.0**, Fabric Loom **1.16.3**, Minecraft **1.21.11**. Mapping'ler intermediary'dir; yeni veya tahmini Yarn API'leri kullanılmaz.

```sh
# Linux'ta Türkçe dosya adı testleri için UTF-8 locale kullan:
LC_ALL=C.UTF-8 ./gradlew clean build
python3 tools/audit_localization.py
```

Windows'ta Java 21 seçili iken `gradlew.bat clean build`. Bağımlılıkların ilk indirilmesi internet ister; Gradle/JDK/cache projeye dahil değildir. `libs/` içindeki Litematica/MaLiLib dosyaları compileOnly'dir; JAR'a gömülmez. İlgili entegrasyon için bunların uyumlu sürümleri ayrıca gerekebilir.

Üretilen kurulum dosyası: `build/libs/albiz-1.0.2-tr.jar`.

## Kurulum
1. Launcher'da Minecraft **1.21.11 / Fabric / Java 21** seç.
2. Oyun kapalıyken mevcut config dizininin ayrıca yedeğini al.
3. `mods` içinden eski Albız/Anubis istemci JAR'ını çıkar; iki sürümü birlikte yükleme.
4. **Yalnızca** `albiz-1.0.2-tr.jar` dosyasını `mods` dizinine koy. Kaynak ZIP veya sources JAR kurulum modu değildir.
5. İlk açılış mevcut ayarları yeni dizine kopyalar; eski dosyalar kalır. Ana modül dosyası `config/albız/albız.json` olur.
6. İstemci dili Görünüm/Arayüz → Dil içinden Türkçe/İngilizce/Otomatik seçilebilir. Minecraft'ın kendi dili ayrıca yönetilir.

SM-A155F/Zalith için bu revizyon fiziksel cihazda denenmedi; GL4ES/MobileGlues shader fallback'leri korunmuştur, uyumluluk garantisi değildir.
